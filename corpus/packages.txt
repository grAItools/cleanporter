# The corpus: real third-party code that `--fix` is run over, to check that a
# rewritten package still imports and still behaves.
#
# Pinned on purpose. An unpinned corpus makes every run a moving target, and a
# regression becomes indistinguishable from an upstream release. Bump these
# deliberately, in their own commit, so the diff in corpus results has exactly
# one cause.
#
# Chosen for variety of import style rather than popularity: a package that
# only ever writes `import x` exercises nothing here. This set covers heavy
# re-export surfaces (mypy, _pytest via pytest), `if TYPE_CHECKING:` blocks
# (libcst, attrs), deep package nesting (django), namespace-ish layouts
# (celery, and kombu which arrives with it) and plain flat modules (pathspec,
# pluggy, packaging).
#
# Packages that ship their own test suite inside the wheel are worth their
# weight several times over: running those tests against a rewritten copy is
# what has actually caught bugs here. libcst is the main one.
